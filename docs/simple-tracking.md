# 极简追番

基于 [wushuo894/ani-rss](https://github.com/wushuo894/ani-rss) 3.2.52，保留 GPL-2.0 许可证。默认入口为 `/#/follow`。

## 日常使用

1. 首次登录后打开「基础配置」，连接 qBittorrent，填写资源库和正式播放目录。
2. 搜索番名，点「追番」。自动检索历史单集资源、补齐并持续追更。
3. 结合具体番剧，在详情中点击已发现的字幕组，按偏好排序。也可一次设置全局认可名单，其他番自动沿用。
4. 在极影视对应分类里关联详情中显示的番剧文件夹。之后新集和版本替换均使用同一目录。

未配置认可名单时，程序等待，不擅自选择字幕组。只认可标题明确标注中文字幕的资源；仅有中文番名不代表有中文字幕。简体、繁体均接受。

默认选择当前可用的最高偏好版本；喜欢的组尚未更新时，先使用其他认可组。开启本番「着急看」后，首次选择以可接受版本的发布时间为先。每集最多自动下载一个进行中的版本；更偏好的版本完成后，再升级正式文件。

## 版本与文件

```text
资源库/
  BangumiID/种子Hash/原始下载文件

正式播放目录/
  番剧名 [bgm-ID]/
    Season 01/
      番剧名 S01E01.mkv
      番剧名 S01E01.zh-Hans.ass
```

原始文件保持原名，支持继续做种。正式文件使用副本，因此同时占用资源库和播放目录空间，适用于跨文件系统；目前不使用硬链接。

切换时先完整准备新文件，使用事务记录与原子替换；失败恢复原版本，重启时恢复未完成事务。旧版本始终留在资源库，可在详情中切回。手动切换会固定该集，点击「恢复自动」才继续升级。不会覆盖正式目录中已有的非本程序管理的同名文件。

qBittorrent 使用独立 `ani-rss-simple` 分类，不进入原版的重命名、删除或洗版流程。同一个种子若已在其他分类或其他路径下载，会提示处理，不擅自移动原任务。

## Windows 启动

解压启动包，双击 `start-simple.cmd`。首次启动如果没有 Java 25 或更高版本，会从 Eclipse Adoptium 下载官方运行时并校验 SHA-256。默认监听 `127.0.0.1:7789`，浏览器自动打开。

初始登录为 `admin / admin`。上游安全设置仍可在 `/#/settings` 访问。

也可以执行 `start-simple.ps1 -Port 17789 -NoBrowser`，或者使用已有 Java：

```powershell
java -jar ani-rss.jar --config=./config --server.address=127.0.0.1
```

## 极空间 Docker

将启动包中的 `ani-rss.jar`、`Dockerfile.simple`、`compose.simple.yaml` 放在同一目录。在 `.env` 中设置宿主媒体目录：

```dotenv
MEDIA_ROOT=/实际的媒体根目录
```

运行：

```sh
docker compose -f compose.simple.yaml up -d --build
```

访问 `http://极空间地址:7789`，配置资源库 `/Media/追番资源`、正式目录 `/Media/番剧`。qBittorrent 必须将同一宿主媒体目录映射为 `/Media`，且程序拥有读写权限。下载器地址填写容器实际能访问的地址，不能把本容器的 `127.0.0.1` 当成其他容器。

极影视关联宿主机对应的正式目录；页面展示的是程序/容器内部路径，按媒体挂载关系换算。

## 当前边界

- 第一版简化流程接入 qBittorrent，支持传统用户名密码和 `qbt_` API 密钥。原版其他下载器的高级流程仍保留。
- 使用 AnimeGarden 的历史分页接口，每 15 分钟检查资源；下载状态每分钟检查，网页每 10 秒刷新。无法保证找回未被收录或失效的旧资源。
- 合集、多视频文件、集数超出季度范围等歧义不擅自映射到单集，需结合真实番剧校正。目前补齐以可可靠识别的单集资源为准。
- 中文标记来自发布标题，属于保守筛选，不是视频内部字幕轨的内容验证；没有明确标记时不自动下载。
- 本地 AI 可辅助核对番名、季度、集数和字幕标记。本次开发已用本机 Codex CLI 检查命名规则，并将发现的问题加入回归测试。它不是运行时必须安装的组件，也不会未经配置扫描媒体文件或直接重命名。
- 极影视的实际识别和播放仍需在极空间设备上联调；当前未调用极影视私有接口。

配置、资源清单、手动选择存放在 `config/simple-tracking.json`，有 `.bak` 备份。下载器凭据只存本地配置，不在追番接口响应中返回。

## 开发验证

使用 Java 25 与 Maven；根目录构建会同时构建 Vue 前端：

```sh
mvn -B -ntp -Dtest=ani.rss.simple.*Test -Dsurefire.failIfNoSpecifiedTests=false package
```

测试覆盖名单与中文过滤、历史补齐、并发限制、偏好升级、手动固定、跨重启恢复、下载器请求、文件完整性、路径边界、事务恢复、字幕语言与命名。

本机配置、运行时、媒体文件和凭据不提交到仓库。上游自动更新保持关闭，避免官方版本覆盖此分支。
